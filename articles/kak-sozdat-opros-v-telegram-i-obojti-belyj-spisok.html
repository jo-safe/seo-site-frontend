Как создать опрос в Telegram и обойти белый список

В Телеграме есть функция создания опросов — для этого нужно лишь знать несколько хитростей. Вот подробная инструкция по созданию такого опроса.

Для того чтобы отправить опрос через мессенджер Telegram (или «Телегу»), необходимо перейти на сайт <a href="https://tlgrm.ru/vote">https://tlgrm.ru/vote</a> или воспользоваться приложением tgrambot@telegram.org. Сайт не очень удобный, но он отлично работает со всеми версиями клиента. Попробовать его можно здесь: <a href="http://tlgrm.me/.">http://tlgrm.me/.</a>

Создание опроса вручную

Чтобы начать создание опроса через веб-сервис tgrm.ru/vote, откройте страницу в любом браузере и выберите пункт меню Create a poll. Затем нажмите кнопку Start polling! →

После этой команды появится форма, которую следует заполнить следующим образом:

  • Напишите текст вопроса. Здесь же укажите количество голосов за каждый вариант ответа;
  • выделите варианты ответов жирным шрифтом. Чем больше вариантов выбора у вас будет, тем сложнее их различать при просмотре списка сообщений;
  • укажите название чата или пользователя, которому отправится сообщение с ссылкой на опрос;
  • если хотите сохранить ссылку на опрос себе на компьютер, поставьте галочку напротив Save link to clipboard. Нажмите Send message → после чего перекиньтесь к следующему шагу.

Отправьте готовое сообщение выбранному пользователю или группе пользователей. Теперь все участники смогут проголосовать по вашему вопросу.

Если вам понадобилось изменить какой‑либо параметр запроса после отправки сообщения, то просто щелкните по нему левой кнопкой мыши. Например, если в списке предложенных вопросов оказался лишний элемент, удалите его одним кликом правой кнопки мышью. А затем снова щелкните по пункту Options из верхнего меню сайта. И повторите описанные выше действия. Процедура полностью повторяется до тех пор, пока результат удовлетворяет вас. Но помните, что добавление новых опций доступно только тогда, когда уже кто‑то проголосовал. То есть добавить новый вопрос без предварительного участия одного хотя бы человека нельзя.

Когда процесс завершен, нажмите на кнопку End polling!, которая станет активной спустя некоторое время. Этот шаг обязательный, иначе ваш запрос останется открытым навсегда.

Установка бота Tgrambot

Кроме ручного способа создания опросов, существует также автоматизированное решение. Оно реализовано ботом под именем @tgrambot@Telegram.org. Его установка осуществляется так же стандартным способом установки любого другого стороннего бота. Вызовите соответствующий поиск вверху экрана приложения и напишите имя указанного сервиса. Кликнув по найденному результату, запустите установку. Далее жмите Next → Add Bot → Set Name. Дальше всё происходит как обычно, даже несмотря на отсутствие текстового поля ввода имени. Следующим действием должно стать нажатие кнопки Get Token, а потом ещё раз Next → Done. Всё, теперь сервис готов к использованию. О том, какие возможности предоставляет этот инструмент, читайте далее.

Запустив установленный вами тгбот, воспользуйтесь командой /start. Это позволит получить текущий статус аккаунта и информацию об использовании. Текстовый ответ выглядит вот так:

Остальные функции работают аналогично предыдущему случаю, поэтому описывать их нет особого смысла. Главное помнить, что использование подобных инструментов возможно только на компьютере, поскольку они интегрированы исключительно в десктопные версии популярного мессенджера. Поэтому перед началом работы убедитесь, что у вас установлено именно такое программное обеспечение, а не мобильное.

Как видите, никаких особых сложностей при создании опроса посредством клиентов Telegram нет. Однако стоит обратить внимание на некоторые нюансы использования данного функционала. Так, например, ответы могут отображаться неправильно, особенно это касается некоторых символов. Также иногда возникают проблемы при обработке длинных текстов. Ещё одна неприятность заключается в отсутствии визуальной обратной связи при проведении голосования. Возможность увидеть результаты сразу после окончания процедуры отсутствует. Таким образом, пользователи вынуждены ждать подтверждения результатов через некоторое время.

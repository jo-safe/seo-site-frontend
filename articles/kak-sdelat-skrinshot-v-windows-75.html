Как сделать скриншот в Windows 75

Наверное каждый из вас не раз сталкивался со случаем когда нужно было показать что-то другому человеку на экране компьютера или поделиться этим моментом с друзьями через социальные сети. В таких случаях лучшим решением является создание скриншота экрана. 

Скриншот всего рабочего стола

Самый простой способ создать скриншот вашего экрана это нажатие клавиш Print Screen (или PrtScn). После этого изображение будет скопировано в буфер обмена и вы сможете просто перенести его при помощи сочетания Ctrl+V в любом графическом редакторе. Более продвинутые пользователи могут воспользоваться программой Paint который поставляется вместе с операционной системой для создания коллажа из нескольких изображений или же сохранить созданный вами снимок прямо в файл изображения. Для того чтобы получить полноценный скриншот вам необходимо запустить программу “Планшет” (“Windows Snipping Tool”) которая также входит в состав программного обеспечения ОС Microsoft. Откройте ее путем поиска программы через меню Пуск или используя поиск в строке панели задач. Далее нажмите кнопку New (+) расположенную справа сверху окна приложения. Затем переместите курсор мыши к противоположным углам вашей рабочей области после чего щелкните правой кнопкой мышки. Теперь у вас есть полный скриншот вашего монитора готовый к использованию. Вы можете удалить ненужные элементы такого снимка как например панель инструментов либо текст при необходимости а затем сохранять ваш результат работы сразу же в виде файла изображения.

Снимок выбранной части рабочего стола

Если вам нужен только определенный участок экрана то воспользуйтесь тем же приложением но вместо кнопки Create new (+), находящейся в верхней части окна кликните по прямоугольной кнопке Select an area of the screen. Это позволит выбрать нужную область на рабочем столе которую можно потом отредактировать согласно вашему желанию и сохранить как обычный файл изображения. Также стоит заметить что эта функция может пригодиться если вам нужно быстро снять фотографию веб страницы без загрузки дополнительных плагинов браузера. Но учтите то что качество получаемого результата будет довольно низким. Поэтому перед публикацией рекомендуется немного улучшить полученный скриншот с помощью доступных средств редактирования встроенных в инструмент “Облегченный планшет”.

Как создавать скриншоты отдельных окон

Имеется отдельная программа под названием Windows Screenshot Capture Program позволяющая делать скриншоты любого открытого окна на вашем компьютере. Она находится среди приложений папки Accessories так что найти её достаточно легко. Однако она содержит лишь одну функцию — возможность снимать фотографии содержимого активного окна поэтому использовать эту опцию имеет смысл только в том случае если все остальные варианты вас совершенно не устраивают. Программа обладает очень простым интерфейсом состоящим из единственной кнопки Start capture которая запускает процесс съемки указанного фрагмента экрана. По окончании действия появляется всплывающее окно содержащее ссылки на сохранения файлов в формате BMP или PNG. Опять же помните о возможности использования функции создания скриншотов средствами самой ОС Microsoft описанной ранее. Так как такой вариант гораздо более удобен чем использование стороннего инструмента.

Заключение

Таким образом даже обладая минимальным количеством знаний пользователь сможет взять на вооружение несколько способов создания скриншотов которые помогут ему решать различные задачи связанные с визуализацией информации отображенной на экране персонального компьютера. Возможность выбора между различными вариантами дает пользователю большую свободу действий ведь он сам определяет каким способом лучше решить поставленную задачу.

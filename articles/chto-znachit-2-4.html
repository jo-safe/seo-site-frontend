Что значит 2, 4?

Попробуйте разгадать загадку о смысле числа «два» и других подобных вопросов.

В этом головоломке есть два варианта развития событий. Сначала вы можете решить её сами или попросить помощи у друга. Если же вам будет сложно справиться самостоятельно, то можно обратиться за помощью к более опытным игрокам в Сети.

Как сыграть?

  • Откройте картинку-подсказку (если играете один) или просто посмотрите на неё вместе со своим другом — тогда не нужно ничего загружать. На ней изображены несколько предметов с прикреплёнными цифрами. К ним также написано их название. Например, рядом с двумя часами указано количество часов. Отсюда следует ответ. Или, например, над одним столом стоит цифра 13; это означало бы, что стол может вместить всего три стула. Так как он пустой, здесь должно располагаться ещё пять штук. И так далее. Нужно определить значения всех прилагательных перед каждым из обозначенных предметами чисел. Запишите ответы и сравните их друг с другом. У кого больше совпадений, тот победил!
  • Если хотите играть онлайн, то откройте карту сайта и заполняйте поля там, где требуется ввести данные. После этого нажмите кнопку Start Game. Можно выбрать режим игры для одного человека либо совместный вариант, когда результаты будут сравниваться сразу после того, как каждый игрок завершит решение задачи. Выигрывает тот участник, который быстрее правильно определит все пары предмет‑число‑значение.

Решение головоломки

  • Два кофейных зерна → две половинки кофемолки.
  • Четыре пальца → четыре стороны коробка.
  • Три ботинка → три носа ремешка.
  • Один сундук → один ключ замка.
  • Десять кубиков льда → десять пингвинов.
  • Одна ложка → одна вилка.
  • Пять банок → пять крышек.
  • Шесть шагов → шесть ступенек лестницы.
  • Восемь леденцов → восемь зубов.
  • Ноль тарелок → нет места под тарелками.
  • Единица яблоко → семь семян.
  • Две луковицы → две лампочки.
  • Ничего — ни одной буквы.
  • Тонны сахара → тонны печенья.
  • Яблоки → девять крошечных червячков.
  • Половинка вафельного рожка → полтора шоколадных капли.
  • Ключ → 9 зубьев ключа.
  • Коробка конфет → четыре палец руки.
  • Куб рубика → пятнадцать цветов.
  • Салат → шестнадцать листьев зелени.
  • Лепестки розы → семнадцать шипов.
  • Капуста → восемнадцать листочков капусты.
  • Сок апельсиновый → двадцать литров фруктового напитка.
  • Картофель фритюрный → девятнадцать кусочков картошки.
  • Лук → четырнадцать слоёв кожуры.
  • Мороженое клубничное → восемнадцать ягод малины.
  • Магнитная лента → двадцать одно полосочек.
  • Пачка хлопьях → двадцать три грамма кукурузы.
  • Банка майонеза → двадцать два пакетика чипсов.
  • Хлеб ржаной → два десятка булочек.
  • Варенье сливовое → двадцать четыре сливы.
  • Жучок золотой → тридцать шесть точек на спине жучка.
  • Пушистая морковь → тридцать восемь волосков моркови.
  • Мёд гречневый → тридцать девять пчел.
  • Бутылка кетчупа → сорок батончиков теста.
  • Абрикос спелый → сорок шерстинок абрикосовой волонки.
  • Фруктовый миксер → сорок четыре оборота в минуту.
  • Банан перезревший → сорок пять коричневых пятен.
  • Лимонад грушковый → сорок шесть пузырьков газа.
  • Перец красный остроперченый → сорок семь красных перчинках.
  • Блинчик кружевной → сорок восемь маленьких дырочек.
  • Ганаш шоколадный → сорок девять небольших трещинок.
  • Печенье мятное → пятьдесят гвоздик мяты.
  • Вишня свежая → пятьдесят пять стебельков черешни.
  • Ананас крупный → пятьдесят шесть малых ананасиков.
  • Мармелад кисельный → пятьдесят семь горошин мармелада

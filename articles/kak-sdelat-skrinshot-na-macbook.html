Как сделать скриншот на MacBook

В этом руководстве вы найдёте подробные инструкции по созданию снимков экрана для любого случая.

Скриншоты — это один из самых популярных способов сохранить точную копию изображения или документа в цифровом виде. Это удобно делать не только при работе за компьютером, но даже со смартфонами (см. «Как снять скриншот». Обзор приложений). Для тех же пользователей Mac существуют специальные функции операционной системы macOS, которые позволяют мгновенно создавать различные типы изображений экрана. 

Как создать простой скриншот всего рабочего стола

  • Нажмите Shift + Command + 3. На экране появится миниатюра сделанного снимка; сохраните её вручную или подождите несколько секунд после появления, пока она автоматически сохранится в папке Документы → Рабочий стол.
  • Если вам нужно добавить к скриншоту какие-то элементы интерфейса программы, например название приложения или адрес страницы сайта, сделайте снимок как описано выше, а затем откройте его в любом графическом редакторе вроде Preview или Photoshop и добавьте нужные данные там. Или воспользуйтесь специальными программами вроде Snagit, Skitch, Lightshot и другими. Они помогут быстро обвести нужную область экрана и дополнить её текстовыми заметками и стрелками.

Как сделать скриншот определенной области экрана

  • Откройте приложение Screenshot Tools, которое входит в состав утилиты OS X Screen Capture Utilities. Если оно ещё не установлено, скачайте программу через App Store, либо перенесите файл screenshottools‑2.9b18.pkg в системный раздел диска и запустите установщик. Затем нажмите Alt + Command + S чтобы открыть эту небольшую панель инструментов в строке меню. Теперь просто кликая правой кнопкой мыши можно выбрать любой участок окна или самого монитора и создать скриншот выбранного фрагмента. Он будет сохранен в той же папке Документы → Рабочий стол.
  • Также есть другой способ создания скриншота части экрана. Чтобы он получился без рамки окон, нажмите сочетание клавиш Option + Shift + Command + 4. Появитель курсор, который принимает форму плюсика (+), когда ведете указателем над окном программы. Когда хотите начать создание снимка, щелкните левой кнопкой мыши, удерживая нажатой кнопку Ctrl. После этого можете перемещать прямоугольник выбора куда угодно на экране компьютера. Отпустив кнопки, получите изображение выбранной вами области дисплея в формате PNG. Оно также сохранится в папке Документов → Рабочий стол.

Как взять скриншот конкретного окна

  • Опять же начнём с того, что установим необходимые инструменты для работы с экранами. Скачать их можно здесь: <a href="http://osxdaily.com/wp-content/uploads/2014/07/ScreenCaptureUtilities_macOSX.dmg?w=1040&h=666&crop=0%2C59.773%2C100%2C30.227&resize=459%2C303.">http://osxdaily.com/wp-content/uploads/2014/07/ScreenCaptureUtilities_macOSX.dmg?w=1040&h=666&crop=0%2C59.773%2C100%2C30.227&resize=459%2C303.</a> Просто дважды щелкаете этот архив, переносите файлы в соответствующие папки (/Applications и /Library) и перезагружаете систему. Затем выбираем окно, которым хотим поделиться, и жмем комбинацию клавиш Shift + Command + 4. Передвигаемся мышью вокруг интересующего нас участка и делаем клик, когда границы выделения совпадают с границами нужного нам элемента. Результат сохранения файла зависит от ваших настроек, поэтому обязательно проверьте содержимое этой папки сразу после первого использования новой возможности MacOS. И если ваш экран слишком большой, лучше установить дополнительный инструмент для снятия фото отдельных областей – LightShot.

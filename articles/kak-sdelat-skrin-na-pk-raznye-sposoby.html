Как сделать скрин на ПК: разные способы

Найти нужный фрагмент поможет специальный инструмент Windows или «Ножницы». Если вам нужно запечатлеть часть экрана — воспользуйтесь встроенным инструментом для создания снимков отдельных участков изображения. А если вы хотите сохранить всё целиком, то воспользуйтесь простыми горячими клавишами.

Как сделать скриншоты всего экрана

Для этого есть два варианта: через стандартный инструмент захвата изображений (входит в состав операционной системы) или используя кнопку Print Screen / PrtScn (может называться иначе).

  • Чтобы открыть приложение по умолчанию для работы со скринами, нажмите правой кнопкой мыши на рабочем столе и выберите пункт New → Screenshot. Также можно вызвать программу из меню “Пуск” поиском. Затем сделайте снимок всей страницы: откройте окно приложения и нажмите на значок камеры. После сохранения файла его можно будет отредактировать прямо здесь же. Но это не самый быстрый способ делать скриншоты.
  • Если у вас нет желания запускать дополнительное ПО, просто запоминаем горячие клавиши. Чтобы снять изображение всего рабочего стола, нажмите одновременно Ctrl + PrtScr (или Alt + PrtScreen). Изображение автоматически сохранится на рабочий стол в формате .PNG под именем screenshot_yyyy-mm-dd_hhmmss.png. Убедитесь только что выбран формат PNG. По умолчанию он может оказаться другим. В таком случае кликните по экрану после нажатия горячих клавишей чтобы выбрать сохранение как картинку PNG. Кликните ещё раз, чтобы увидеть сохранённое фото. Обратите внимание, что файл появится только после того как экран полностью проявит себя — то есть покажется весь интерфейс компьютера, включая ярлыки приложений и папок. Поэтому этот метод хорошо работает в спокойном режиме использования PC. Когда компьютер перегружен, например загружается игра Genshin Impact или Minecraft Roblox, могут возникнуть проблемы. Кроме того, необходимо включить опцию отображения окна редактора скриншотов перед тем, как пользоваться этим способом. Выполняете следующие действия. Откройте Пуск → Параметры → Система → Снимок экрана и запись. Переключите ползунок Allow apps to capture screenshots and screen recording on this computer в положение On. Теперь щелкните ссылку Advanced settings for capturing windows when using the Snipping Tool. Далее поставьте галочку напротив Always save full-screen snapshots as files in my photos library. Это позволит избежать проблем при работе с компьютером при необходимости быстрого создания скриншота.
  • Сочетания клавиш работают также при использовании виртуальной клавиатуры. Не забывайте об этом, когда пользуетесь ноутбуками с сенсорными дисплеями.

Так как все перечисленные выше варианты относятся к использованию одного и того же инструмента, давайте рассмотрим подробнее возможности программы Snip & Sketch. Она доступна всем пользователям ОС Windows 10 и более поздних версий. Программа позволяет создавать различные виды снимков экрана, а также редактирует их непосредственно внутри приложения. Здесь же можно добавлять текст, рисунки и другие элементы оформления, затем сразу поделиться результатом в соцсетях или отправить email. Все эти функции делают Snip & Sketch удобной альтернативой сторонним программам вроде Lightshot или Greenshot.

Как сделать скриншоты определенных областей экрана

Сохранить конкретную страницу вебсайта помогут специальные инструменты Windows – “Веб‑страница” и “Веб‑элементы”. Они позволяют выделить любую площадь рабочей поверхности вашего монитора и создать её копию в виде отдельного изображения. Расположение этих инструментов находится в папке System Tools раздела Accessories. Вот несколько примеров их применения. Например, создавая иллюстрации для текстовых сообщений или записей блога, удобно использовать функцию Web Elements, позволяющую выделить необходимый участок информации. Или скопировать адресную строку браузера Chrome для публикации ссылки в социальных сетях. Ещё один вариант использования подобного функционала заключается в создании мокапов сайта с целью тестирования различных гипотез дизайна страниц. Опять же, такой подход гораздо быстрее обычного метода создания скриншотов области экрана.

Стоит отметить, что некоторые игры предоставляют возможность создавать скриншоты посредством специальных игровых средств ввода. Например, для Genshin Impact существует горячая клавиша F12, которая делает мгновенные снимки экрана. Таким образом разработчики предлагают готовое решение этой задачи именно для своей разработки. Аналогичная функция имеется и в игре Roblox, где скриншотами делается одним нажатием кнопки Caps Lock. Разработчики некоторых игр специально включают такую поддержку в качестве бонуса для своих игроков.

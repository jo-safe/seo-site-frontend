Как переустановить Windows на SSD

В этой статье мы разберем процесс установки новой ОС (Windows) на новый или существующий диск/SSD-диск. Мы также обсудим преимущества использования нового SSD для хранения вашей основной OS и даем несколько советов по ее оптимальной работе после завершения процесса Установки.

Форматируем старый HDD / устанавливаем новую систему

Если вы уже заменили свой жесткий диск (HDD), то не забудьте удалить все разделы вашего старого накопителя перед тем как приступить к установке Windows 7. Это можно сделать через программу «Дисковое управление» в панели управления (Пуск -> Панель управления -> Система и безопасность -> Административные инструменты). Выберите нужный раздел из списка слева и нажмите кнопку удаление (удалить том) справа. Все данные будут безвозвратно стерты. После этого будет доступно неопределенное пространство, которое может использоваться под любую файловую систему. Рекомендуется использовать NTFS. Нажмите правой кнопкой мыши по свободному пространству и вызовите контекстное меню — кликните “Создание простого раздела”. Затем дважды щелкните по созданному диску и следуйте инструкциям мастера создания файла системного образа восстановления. Убедитесь, что ваша новая целевая секция имеет букву C:\. Остальные же могут именить любые другие буквы. Для продолжения работы необходимо загрузиться со специального установочного носителя. Можно записать образ Windows 7 на DVD или создать USB флешку размером более 4 ГБ при помощи программы Rufus – ссылка находится ниже. Запустите компьютер c выбранным носителем и выполните указанные шаги инсталлятора. По окончанию процедуры перезагрузите ПК и наслаждайтесь быстрым стартом и работой новых программ!

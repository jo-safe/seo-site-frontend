Как избавиться от ненужного приложения на Mac

В отличие от Windows, в которой можно просто перетащить ярлык из меню «Пуск» или папки «Программы», macOS не так проста к пользователю. Программа может оставаться в списке даже после удаления ее файлов, а некоторые могут оставлять следы своего пребывания по всему компьютеру. По этой причине перед тем, как выкинуть программу, лучше узнать о правильном порядке действий для того чтобы не оставить за собой следов.

Удаляем саму программу (приложение)

  • Определите нужную вам программу;
  • Найдите значок этого приложения в папке «Приложения». Если его нет там — значит оно находится где-то еще;
  • Перенесите этот значок в корзину. Это действие запустит процесс удаления файла вместе со всеми связанными файлами и настройками;
  • Нажмите правой кнопкой мыши по значку Корзины и выберите команду «Удалить»;
  • В появившемся диалоговом окне нажмите кнопку «Отменить»:
  • Повторите эти действия в случае наличия нескольких экземпляров одной и той же программы. Обычно это означает наличие более одного дистрибутива одной программы, установленных вами самостоятельно. После выполнения этих шагов все копии должны исчезнуть.
  • Если программа была куплена через App Store, то она будет находиться в разделе «AppStore / Установленные”. Просто найдите нужное приложениe и удаляйте его. Здесь же можно посмотреть историю покупок, если таковая имеется у вас.
  • Представим ситуацию, когда программе требуется перезагрузка компьютера для завершения процесса установки. Можно воспользоваться специальным инструментом System Profiler. Он позволяет проверить статус системы и убедиться что все процессы корректно выполнены. Для запуска необходимо найти эту программу по поиску Spotlight, затем выбрать раздел “Software” → Applications. Здесь отображается список всех загруженных системных процессов. Кликните дважды по интересующему вас процессу и дождитесь окончания работы. Затем кликните снова по этому пункту списка – появится сообщение об окончании обновления ПО. Нажатие кнопки Update приведет к скачиванию последней версии обновленной системы. Также здесь находятся ссылки на страницы поддержки Apple для каждого отдельного пункта.

Избавляемся от всего лишнего

  • Используем Finder для поиска файлов связанных с программой. Открываем окно Findera выбираем View > Show All Files , либо Command + Shift + A . Выбираем закладку Search и набираем название программы в поле Any Field ;
  • Кликаете два раза мышью по строчке File Type и открывается подменю. Там стоит отметить тип файлов, которые ассоциируются с вашей программой. Например, файлы формата mp3 будут связаны с iTunes и т.п.;
  • Делаем поиск файлов библиотеки браузера Safari. Заходим в Preferences > Advanced откройте вкладку General, жмете кнопку Show Develop menu and Web Inspector -> Open Debugger Window и далее Documents/Preferences Folder, находите файл com.apple.Safari.plist и перемещаем его в корзину. Делается таким образом потому что стандартный метод очистки данных не работает! А теперь смотрите пункт выше, но вместо MP3 укажите HTML, HTM или другие типы веб-файлов;
  • Всегда полезно иметь резервирование своих документов на внешнем жестком диске, облачных сервисах вроде iCloud Drive или Dropbox. Они помогут восстановить любые данные при возникновении каких-либо проблем с вашим основным накопителем.
  • Статья рассказала лишь поверхностные знания об удалении программы и оставшихся следях от нее на вашем МакБуке. Но всегда есть вероятность возникновения дополнительных сложностей во время такого мероприятия. Поэтому настоятельно рекомендуем ознакомиться с инструкцией Apple касательно удаления отдельных элементов операционной системы macOS. Эта статья поможет избежать многих неприятностей, возникающих при работе с системой без должной подготовки.

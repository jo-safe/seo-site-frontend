Как переустановить Windows 7 64-bit

Многие пользователи столкнулись со следующей проблемой — после обновления на Windows Vista или Windows XP их компьютеры стали работать намного медленнее (или не работали вообще). И если в случае с обновлением до Windows Vista это было бы вполне понятно, то что же делать с тем фактом, что для перехода к более новым версиям ОС нам придется снова устанавливать систему заново? 

Что нужно сделать перед началом работы

  • Скопировать все свои данные на внешний носитель информации;
  • Создать резервную копию системных файлов диска C:\Windows\System32 – возможно, вам понадобится восстановиться из нее позже;
  • Проверить наличие всех необходимых драйверов устройств вашего компьютера (лучше всего скачать все необходимые файлы заранее);
  • Скачать образ Windows 7 64/32 bit ISO-файла (если еще этого не сделали) с официального сайта Microsoft (<a href="http://www.microsoft.com/).">http://www.microsoft.com/).</a> Образ можно записать сразу либо потом, но лучше использовать специальные программы, которые могут создавать загрузочные USB-накопленные устройства. Например, такие как WinToUSB или Rufus.

В принципе этим мы закончили подготовку к установке новой версии Windows. Теперь вы можете смело приступать к ее инсталляции! Но прежде чем приступить непосредственно к процессу установки необходимо выполнить несколько важных действий по подготовке вашей системы к работе под управлением этой операционной системы. А именно:

Убедитесь, что ваш жесткий диск имеет достаточно места под новую версию Windows. Это примерно 18 ГБ (для 32 битной версии), а так как некоторые приложения занимают больше нескольких десятков гигабайт каждый, то советую выделить около 40–50 Гб минимум. Если у вас есть второй физический раздел, который будет служить местом размещения пользовательских данных и приложений, тогда его можно оставить без изменений. Однако, если такого раздела нет, рекомендуется удалить существующий дополнительный раздели, объединив свободное пространство вместе с основным разделом, чтобы создать одно большое хранилище файлов. Для этого воспользуйтесь специальной программой Disk Management, которая входит в состав стандартного комплекта инструментов операционных систем семейства Windows. Выберите нужный раздел, кликните правой кнопкой мыши и нажмите “Удалить том”. После удаления создайте новый том размером, соответствующим вашим потребностям, используя опцию Create New Volume, доступную после выполнения предыдущего пункта меню. Не забывайте про формат файловой системы нового раздела NTFS, она наиболее оптимальна для современных версий Windows. На этом этапе также важно отметить возможность включения режима быстрого старта для повышения производительности ПК. Эта функция присутствует только в релизе Windows 7 Professional for Workstations и Ultimate edition, поэтому убедитесь, что ваша лицензия позволяет ей пользоваться. По умолчанию режим быстрых запусков отключен, однако он может активироваться автоматически при первом старте OS. Также стоит помнить о возможности использования Secure Boot, обеспечивающего защиту ваших персональных данных. Ее активация позволит избежать многих проблем безопасности в будущем, хотя данный пункт является необязательным для большинства пользователей. Последним штрихом подготовки становится создание точки восстановления системы, позволяющее вернуться к последнему работоспособному состоянию аппаратуры и ПО в случае возникновения непредвиденных ситуаций. Доступность данного элемента определяется типом издания Windows 7 Pro / Enterprise Edition. Он встроен прямо в интерфейс инструмента System Restore и запускается простым нажатием кнопки Scan For Affected Files in Current Configuration. Тщательно проверьте настройки BIOS и UEFI материнской платы. Процессор должен поддерживать набор команд x64, а оперативная память иметь объем минимально равный требованиям выбранной вами редакции ОС. Отсутствие одного из этих условий сделает вашу жизнь очень сложной даже после успешной установки Windows 7.

Переходите к самой инсталляцией системы. Следуя инструкциям мастера установки Windows, выбираете язык локализации, регион страны и тип ввода текста. Затем происходит процесс анализа аппаратного обеспечения с целью определения совместимости компонентов ПК с будущей системой. Когда этот этап завершается, следует выбрать между чистой установкой Windows 7 и миграции существующих настроек, профилей пользователя и данных из прежней системы. Рекомендуем очистить весь диск и установить свежую копию операционки, поскольку многие проблемы возникающие уже через некоторое время после апгрейда связаны с конфликтами и ошибками в реестре и других областях хранения параметров системы.

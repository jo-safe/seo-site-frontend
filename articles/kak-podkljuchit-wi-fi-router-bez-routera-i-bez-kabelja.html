Как подключить Wi-Fi роутер без роутера и без кабеля

В последнее время я столкнулся со сложной проблемой — как быстро настроить вторую точку доступа на даче (которая не имеет подключения к интернету) при наличии только одного старого компьютера в доме? Задача может показаться непростой, но решение оказалось довольно простым! ;)

Что нам понадобится для решения задачи?

  • Два маршрутизатора/роутера;
  • Устройство поддержки протокола WDS или его аналогов (в нашем случае это был TP-Link TL‑WR841G);
  • Ключ защиты точки доступа второго роутера, который мы будем подключать.
  • Примечание: Для некоторых устройств поддержка технологии передачи данных между двумя точками доступа реализована по умолчанию, поэтому необходимо будет просто включить соответствующую опцию и ввести ключ шифрования сети. Однако если этого нет в вашем устройстве, придется искать альтернативные способы настройки соединения точек доступа. Например, можно использовать устройства компании Ubiquiti Networks, которые поддерживают эту функцию. Но они стоят дороже обычных моделей. Вот ссылка на их сайт: <a href="http://www.ubntnetworks.com/products/airmax_wireless_bridges/index.html">http://www.ubntnetworks.com/products/airmax_wireless_bridges/index.html</a>

Как найти нужные параметры для первого шага работы?

Первый шаг заключается в том, чтобы получить информацию о первом роутере (точке). Если у вас есть доступ к этому компьютеру, где находится этот роутер, вы можете зайти в него из браузера, так же как обычно делаете с любыми другими домашними сетевыми службами. Выберите ваш адрес IP-адрес, например, «<a href="http://192.168.0.1».">http://192.168.0.1».</a> Обычно логин и пароль стандартные admin / admin либо guest / password. На странице авторизации следует обратить внимание на следующие пункты меню:

  • Wireless Settings → Wireless Mode — здесь вам нужно выбрать режим AP mode;
  • Advanced settings → MAC Address Filtering — отключите проверку адресов клиентов;
  • Security → Security mode — установите WPA-PSK + TKIP или RSN+TKPI, а также укажите имя вашей сети и ее пароль;
  • DHCP Server — убедитесь, что сервер работает правильно, иначе клиентам не выдастся корректный IP-адрес;
  • Firewall → Access Control List – уберите галочку Allow all incoming traffic from any source IP address to the router’s LAN interfaces;
  • Перезагрузите устройство после внесения всех изменений. Теперь все готово для следующего этапа работы.

Подключение двух точек доступа

Следующий этап состоит во включении режима моста (Bridge), предназначенного именно для того случая, когда вторая точка доступа должна стать продолжением первой. Процесс выполняется аналогично первому шагу. Заходим в раздел Advanced settings -> Wireless Bridge and повторно выбираем DHCP Client Mode. После перезапуска системы роутер начнет работать в режиме клиента, получая данные о конфигурации другой сети. Остается лишь указать канал передаваемых сигналов, идентичный тому каналу, которым используется основной роутер. И наконец, указываем название нашей новой сети и ее пароль. Перезапуск и вот ваша сеть уже готова!

Как переустановить Windows с помощью BIOS

Инструкции по обновлению операционной системы без необходимости загрузки установочного диска или флешки на компьютере.

Если ваш компьютер работает медленно, часто зависает, не запускается после обновления драйверов в безопасном режиме — возможно пришло время полностью обновиться. Чтобы это сделать, можно воспользоваться образом установщика Windows, который вы скачали ранее для записи его на DVD-диск или флэшку USB (или использовать встроенную функцию «Восстановление» → «Переинсталляция образа»). Но есть ещё один способ, подходящий только если у вас нет доступа к оптическому диску или накопителю со свежей копией ОС. Это простейший метод установки новой версии Windows прямо из текущей системы через меню BIOS/UEFI. Обо всех нюансах этого способа мы сейчас расскажем подробнее. :)

Шаг №1. Убедитесь в наличии достаточного места на системном разделе жёсткого диска

  • Для стандартной домашней сборки потребуется минимум около 32 ГБ свободного пространства;
  • для профессиональной версии Windows необходимо хотя бы 40–48 Гб свободной памяти.
  • Если этот параметр недостаточной величины — сделайте очистку ненужных файлов и папок. Для удаления старых временных файлов используется программа CCleaner («Очистка»→«Удалить мусор») либо команда %windir%\Temp% в проводнике. Также удалите все программы и приложения, которыми больше не пользуетесь, а их остатки обязательно почистите с помощью той же утилиты. В общем дедушкам лучше вернуться к старшим версиям OS! ;)

А теперь всё готово для продолжения процесса установки. Переходим ко второму пункту инструкций.

Шаг №2. Запустите интерфейс настроек компьютера через командный режим

Откройте поисковую строку задач и запустите консоль администратора командой cmdrunas /admin . Сразу появятся запрос подтверждения прав суперпользователя и окно CMD, позволяющее управлять системой со всей её мощью. Не пугайтесь этих предупреждений безопасности и смело продолжайте работать с инструментом. Здесь вам понадобится ввести специальную команду, чтобы перейти непосредственно к выбору параметров инсталляции Windows. Напишите msconfig /appvbootmode=full и нажмите клавишу Enter. После выполнения команды следует открыть раздел восстановления операционных систем в свойствах вашей системы. Для этого воспользуйтесь кнопкой «Просмотреть». Далее жмите F9 и выбираете опцию «Параметры диспетчера заданий», которая открывает диалоговое окно System Configuration Utility.

Теперь кликните правой кнопкой мыши на строке Boot options и укажите выбор Advanced Options → Repair Your Computer > Troubleshoot > Advanced Options > Command Prompt. Так перед вами появится инструмент управления настройками BIOS/UEBI – главное меню материнской платы вашего ПК. Тут нужно найти пункт Update to a New Operating System and Install it Now. Подтвердите действие нажатием кнопки Yes и дождитесь появления экрана выбора источника программного обеспечения. Выберите вариант Upgrade this PC now. По окончанию операции Windows будет полностью готова к работе – как будто вы никогда ничего устанавливать не собирались… ;)

Вот таким образом легко и быстро можно установить новую версию Windows, не тратя времени на поиск нужного носителя и создание резервной копии своих данных. Процесс занимает всего несколько минут и подходит практически всем пользователям современных персональных вычислительных машин. Согласитесь, что намного проще? :)

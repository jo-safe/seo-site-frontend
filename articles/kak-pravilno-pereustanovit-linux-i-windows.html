Как правильно переустановить Linux и Windows

В этой статье я расскажу о том как можно сделать чистую установку Linux или Windows.

Подготовка к процессу переустановки системы

  • Создайте точку восстановления в системе для того чтобы после проблемной переустановки вы могли вернуться на предыдущий стабильный образ ОС (если он есть). Нажмите «Пуск» → «Все программы», откройте папку «Система защиты восстановлением системы». Кликните правой кнопкой мыши по пункту «Восстановление системных настроек» и выберите опцию «Проверить настройки последней точки восстановления…»;
  • Скопируйте все ваши данные из папок Documents, Downloads, Desktop, Pictures, Music, Videos, Favorites и др., которые вам нужны в другое место, например CD-диски, внешний жесткий диск USB Flash Drive;
  • Удалите временные файлы. Для этого нажмите клавишу Win+R, затем напишите %TEMP% и запустите команду очистки диска CCleaner’ом. Если у вас нет такой программы — скачайте её здесь <a href="http://www.cclearner.com/download/;">http://www.cclearner.com/download/;</a>
  • Внесите изменения в файл hosts (для пользователей Виндоса), который находится в директории C:\System32\drivers\. Откройте его через блокнот. Найдите строку local_service=127.0.0.1 и удаляйте каждую такую строку, если таковая имеется. Это поможет избежать многочисленных рекламных всплывающих окон во время переустановки операционной системы. После чего закройте документ. В случае необходимости перезагрузите ваш ПК после выполнения этих действий.

Процесс переустановки Windows

  • Перед тем как начать процедуру переустановки необходимо ввести установочный носитель со свежей версией вашей любимой ОС. Скачать образы Windows 8.1 Preview, Windows 7 Home Premium SP1 x86 & x64, Windows Vista Home Basic SP2 x86 (SP1) & x64, Windows XP Professional Edition SP3 – вы можете скачать их бесплатно непосредственно со сайта Microsoft. Помните что при этом будут требоваться лицензионный ключ и серийный номер продукта. Но это уже детали! ;)
  • После успешного запуска компьютера будет предложено выбрать язык интерфейса, клавиатуры и региональные стандарты. Выбираем то, которое нам подходит. Затем подтверждаем эти параметры нажатием кнопки Next и выбираем пункт Install now («Начинать установку»). Далее появляется экран выбора версии операционной системы, а также условия использования программного обеспечения. Ознакомившись с ними, соглашаемся на продолжение процесса установки путем клика по кнопке Accept Now (“Принять сейчас”).
  • Далее начинается этап подготовки к следующему шагу — выборе раздела жесткого диска, где планируется установить новую систему. Здесь нужно внимательно изучить список разделов, доступных в вашем компьютере. Удалить все существующие разделы не обязательно, но рекомендуется так же подготовить новый раздел под будущую версию Windows. Не забывайте перед этим скопировать свои важные документы куда либо еще. Теперь открываем меню пуск, находим программу Disk Management и щелкаем по ней дважды мышью. Переходим в закладку Volume и создаем несколько новых разделов нужного размера и типа файловой системы NTFS. Рекомендую создать отдельную секцию размером ~5 гигабайт под сохранение файлов ОС. Делается это следующим образом: кликнуть правой кнопкой мышки по свободному месту на разделе HDD, выбрать Create Simple Volume (“создание простого объема”) и следовать указаниям мастера создания нового раздела. Завершив эту работу, повторяете действия три раза снова. Итого получаем четыре раздела на одном физическом накопителе вашего ПК. Один — основной, содержащий OS, другой — для хранения ваших документов, третий — для сохранения снимков системы и четвертый — для кеш-файлов обновлений ПО. Сохраняем внесенные нами изменения, закрываем окно Partition Manager и продолжаем процесс инсталляции новой версии ОС. Вопрос об использовании ранее использованного раздела игнорируем и переходим далее. Следующий шаг заключает в себе выбор пункта Custom (Advanced): Advanced (продвинутая настройка) — позволяет создавать новые разделы, редактировать размеры существующих и тд. Мы хотим именно так.

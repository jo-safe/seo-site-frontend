Как обойти белые списки в Happ

Когда я впервые услышал о технологии «белых списков», то подумал — что тут сложного? Ну так и есть! Белый список содержит все те сайты, которые вы хотите посещать без проблем или просто разрешить на своем компьютере. И это очень удобно для тех людей, у которых компьютер используется не только им самим (например, дети). Можно добавить сайт школы к белому списку, а остальные заблокировать. Как же сделать белый список в сервисеHapp, который предназначен исключительно для детей? Оказывается, проще всего его создать прямо на сайте компании <a href="http://happ.com/.">http://happ.com/.</a> Но мы будем искать другие варианты :)

Создание списка через почту

Сначала нужно зарегистрироваться в сервисе Happ по адресу www.happ.com/signup. После того как создали аккаунт можно открыть новый лист (New list) и ввести туда адрес сайта, например school.ru. По умолчанию сервис позволяет создавать лишь один такой список, но достаточно быстро появляется возможность купить дополнительный пакеты таких листов. Если захотите расширить возможности вашего контроля над интернетом ваших детворы, придется раскошелиться :) Впрочем, всегда можно начать с одного листа, чтобы понять насколько полезен вам этот инструмент. Затем переходим на вкладку Settings, где видим несколько настроек этого первого листа. Самое интересное здесь находится в разделе “White List”. Здесь будет указан URL-адрес нашего нового списка. Он выглядит примерно вот так : <a href="https://www.happ.com/list/{кодовый_токен}.">https://www.happ.com/list/{кодовый_токен}.</a> Токены генерируются автоматически при создании каждого из новых списков. Запомните свой код, он нам понадобится чуть позже. Теперь жмем на кнопку Send email invitation to child’s parents and send them this link so they can accept it on their own device with a web browser. Открывается новое окно со ссылкой, которую надо отправить вашим детям. У них там появится сообщение типа Welcome in the safe world of Happ!, далее они смогут подтвердить свое участие в программе.

Обход ограничений с помощью прокси-сервера

Так ведь было бы неплохо использовать тот же самый механизм для взрослого пользователя компьютера. Чтобы достичь этой цели необходимо воспользуться сторонним приложением для работы с HTTP прокси серверами под названием Proxy Switcher. Оно распространяется абсолютно бесплатно, однако существует версия Pro версии продукта с более широкими возможностями. Скачать бесплатную версию можете по этому адресу <a href="http://proxyswitcher.sourceforge.net/.">http://proxyswitcher.sourceforge.net/.</a> Добавляем наш ранее полученный url-лист к настройкам Proxy Switcher. Для этого открываем главное меню программы и выбираем пункт Preferences->Proxies, затем добавляете новую запись путем нажатия кнопки Add proxy server… Далее копируем ссылку на ваш whitelist .В поле Hostname указываем ее полностью включая /list/{код]. Остальное оставляем стандартным. Проверяйте правильность введенной информации кнопкой Test connection now! , после чего сохраняетесь щелканув OK. Наконец, запускаем браузер, устанавливая режим работы Proxyswitcher через контекстное меню справа сверху в окне веб-браузера. Мы имеем право говорить о том, что теперь можем спокойно ходить по ссылкам нашего white list'а без каких либо преследований со стороны службы безопасности Happy ;)

Кстати, если кто-то из вас еще думает об использовании данного инструмента в образовательных целях, советую обратить внимание на проект Safe Web for Schools, реализуемый компанией Net Nanny. Это одна из немногих организаций, которая специализируется именно на безопасном интернете для школ. Хотя продукт их платный, зато он имеет массу дополнительных возможностей помимо создания белх спиков.

Как переустановить Windows 10 на ПК, войти в BIOS и сделать скриншот

На всякий случай сохраните эти полезные функции у себя под рукой — они могут понадобиться вам не раз.

Как запустить «Восстановление системы» для переустановки Windows 10

Этот способ подходит только тогда, когда вы знаете пароль администратора компьютера или можете его восстановить (если забыли). Если же система была защищена PIN-кодом или другими средствами защиты, этот метод работать не будет. Для их обхода придётся прибегнуть к другим способам восстановления доступа к компьютеру. Чтобы начать восстановление, выполните следующие действия.

  • Выключите компьютер и перезагрузите его ещё дважды подряд. После этого должен запуститься процесс загрузки со специального экрана. В нём нужно выбрать пункт Восстановление вашей машины и продолжить выполнение инструкций на экране. Затем появится меню выбора типа установки операционной системы. Здесь можно установить программу очистки диска из раздела настроек, а после чего вернуться к выбору точки восстановления. Выберите точку времени, чтобы вернуть систему к прежнему состоянию. Иначе просто нажмите кнопку Устранение неполадок → Дополнительные параметры → Переустановка ОС. Это потребует около часа свободного времени. Процесс пройдёт без ввода любых данных пользователя. Не забудьте сохранить важные данные перед началом работы!

Как попасть в BIOS

Некоторые компоненты материнской платы должны включаться раньше всех остальных устройств, что позволяет им подготовить компьютер к работе других элементов. Обычно это достигается с помощью специальных комбинации клавиш, которые активируют входное окно настройки параметров компьютера. Но тут есть одна проблема: разные производители используют свои собственные сочетания символов. Поэтому запоминать точное нажатие каждой клавиатуры нет смысла. Зато мы собрали список самых распространённых вариантов запуска интерфейса BIOS. Попробуйте один или несколько из них, пока ваш компьютер не включится правильно. Обратите внимание, что некоторые модели ноутбуков имеют отдельные кнопки для этой цели, например ASUS ZenBook Flip. Такие варианты также стоит проверить как вариант решения проблемы. А вот если нужная кнопка отсутствует совсем, то придётся использовать более сложный алгоритм действий, описанный ниже.

Перед тем как перейти к этому методу, убедитесь, что ваша версия Windows действительно поддерживает UEFI Secure Boot. Сделать это очень просто: зайдите в приложение Параметры → Обновление и безопасность → Разработка и расширенные возможности безопасности → Безопасная загрузка и проверьте наличие опции “Включение безопасной загрузки”. Ну а далее процедура такая.

1. Откройте командную строку от имени Администратора. Так её можно найти через поиск по системному блоку или правой кнопкой мыши по пункту Пуск -> Панель управления -> Система и информация о системе -> Инструменты администрирования.

2. Теперь сделайте снимок содержимого дисплея и откройте полученный файл. Именно здесь нам нужна эта функция. Мы будем искать там номер вашего процессора. Например, Intel Core i3‑8109G4T. Он состоит из трёх частей. Первая часть обозначает поколение микропроцессора; вторая — тип самого CPU; третья — модель конкретной версии чипа. Первую букву третьего сегмента надо преобразовать в числовое значение согласно таблице соответствия. Соответственно, наше устройство соответствует цифре 7.

Таблица соответствия первой буквы третьей части номера процессора вашему количеству доступных режимов запуска в BIOS: A = 0, B = 1, C = 2, D = 3, E = 4, F = 5, G = 6, H = 7, I = 8, J = 9, K = L = M = N = O = P = Q = R = S = T = U = V = W = X = Y = Z = 10.

3. Когда найдёте соответствующую таблицу выше цифру, переместите курсор над ней в открывшемся окне браузера и удерживайте левый клик мышки, одновременно находясь на той строке таблицы, которая указывает режим перехода в BIOS. Например, указанная ранее нами машина имеет набор характеристик ABCDEFGHJ, поэтому выбираем последнюю позицию в ряде значений режима – восьмую сверху. Далее жмем Enter.

4. Компьютер автоматически начнет переход в BIOS. Используйте одну из упомянутых выше комбинаций клавиш, чтобы подтвердить успешность операции. Дальше всё зависит от производителя и конфигурации ваших компонентов. Возможность получить доступ ко всем настройкам ограничена функциона

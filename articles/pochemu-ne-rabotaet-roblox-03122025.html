Почему не работает Roblox 03.12.2025

Всё дело в странной дате на сервере игры — её нужно исправить вручную.

С 3 декабря у многих пользователей начались неполадки при запуске популярного сервиса Roblox. Но проблема связана со специфической строкой кода внутри программы, а вовсе не глобальный системный сбой или задержка из-за новой версии операционной системы Windows 11.

Что случилось?

  • Пользователи жалуются, что приложение запускается без ошибок, но не открывает главный экран с доступными для посещения локациями игр. В некоторых случаях окно просто закрывается после загрузки приложения. Игроки также сообщают о проблемах при попытке войти в свой аккаунт через веб‑версию платформы (roblox.com). Упоминание этой даты указывает именно на то, что это ошибка сервера. Так как эта дата всё ещё в будущем, скорее всего, она была задана случайно разработчиками сервиса при тестировании новых функций или исправлении багов.
  • Ранее подобные ошибки возникали у игроков iOS и Android, когда версия их устройства оказывалась выше поддерживаемой минимальной версией ПО игрового клиента. Однако тут речь идёт об ошибке сервера, так что пользователи разных устройств испытывают схожие проблемы одновременно. Возможно, причина кроится в том, что некоторые функции работы сервиса основаны на старом коде и требуют определённых параметров времени работы. На текущий момент официальных комментариев от техподдержки Roblox нет. Вероятней всего, компания разбирается в произошедшем. Пока же есть несколько вариантов решения возникшей ситуации. Их можно попробовать самостоятельно.

Как решить проблему

Если вы столкнулись с подобным явлением, попробуйте перезапустить компьютер или мобильное устройство. Затем снова запустите игру и проверьте работу сервиса. Иногда достаточно такой простой манипуляции, чтобы устранить временные технические сложности. Также может помочь обновление самой ОС вашего ПК или смартфона. Проверить наличие свежих патчей можно следующим образом. Для этого выполните следующие действия.

После установки обновлений следует повторно проверить работоспособность Roblox.

Этот способ поможет вернуть к жизни программу, если система обнаружит отсутствие установленного компонента, отвечающего за корректное отображение интерфейса Roblox. Это происходит чаще всего при переустановке ОС или повреждении файлов. Запустив PowerShell, необходимо ввести команду get-windowsoptionalfeatures | where state = “Disabled” затем выбрать компонент DirectX End User Runtime Web Installer и активировать его командой enable-WindowsOptionalFeature –Online -WebComponentID ClientRuntimeHTML. Выполненная последовательность действий приведет к появлению окна активации компонентов Microsoft Edge (браузера), который используется на стороне клиентов для визуализации графических эффектов в игре. Рекомендуем дополнительно удалить все файлы кеша браузеров и очистить историю просмотров перед тем, как открыть Roblox вновь.

Попытка форсированной синхронизации данных между клиентом и серверами Roblox обычно помогает «разблокировать» зависший процесс авторизации. Чтобы выполнить эти шаги, откройте командную строку Windows и следуйте инструкциям ниже.

  • Введите в поиске терминал и нажмите Enter;
  • откройте появившийся список программ поиском и кликните правой кнопкой мыши по пункту Windows Terminal, затем выберите пункт Run as administrator (“От имени администратора”), либо создайте ярлык этого пункта прямо на рабочем столе, нажав Shift+правой кнопкой мышки → Create shortcut (“Создать ярлычок”) и запустите его таким способом;
  • вызовите панель управления программой, нажав Ctrl + ,;
  • измените режим выполнения команды с Power Shell в Command Prompt (“Командная строка”);
  • пропишите в поле ввода cmd /c net stop robloxservice && cd C:\Users\[Ваше имя пользователя]\AppData\Local\RobloxPlayer\sharedstate\\ && del *.mdf*.ldf\*.* /s/q && net start robloxservice && exit&& restart ;
  • дождитесь окончания всех процессов;
  • перезагрузите систему и попытайтесь еще раз установить соединение с сервером Roblox.

Данный метод подразумевает полное удаление клиентского файла настроек RobloxService.exe, ответственного за поддержание подключения игрока к службе. Перед началом рекомендуется сделать резервную копию такого файла в безопасном месте. Далее следовать указаниям ниже.

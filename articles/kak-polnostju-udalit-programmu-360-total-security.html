Как полностью удалить программу 360 Total Security

Достаточно выполнить несколько простых действий в панели управления Windows или воспользоваться специальным утилите.

Самый простой способ — нажать кнопку «Удалить». Но при этом часть файлов останется в системе, а после переустановки могут возникнуть проблемы с программой. Чтобы избежать этого, выполните следующие шаги. 

  • Откройте меню «Старт», нажмите правую клавишу мыши по значку приложения и выберите пункт «Изучить». В открывшемся окне щелкните правой кнопкой мыши по ярлыку 360 Total Security и также вызовите контекстное меню. Выберите команду «Показать родительский процесс». Это откроет диспетчер задач.
  • В нём найдите строку Process Host (exe) и дважды кликните по ней. После запуска командной строки скопируйте весь текст со страницы свойств процесса и сохраните его в текстовый файл без расширения (.txt). Например, можно использовать блокнот для этой цели. Сохраняем документ как uninstall_list.txt.
  • Вернёмся к процессу. Закройте вкладку Properties, затем выделите все процессы и щелканье левой кнопкой мыши по строке Task Manager File -> Save As… введите имя файла, например UninstallList28‑11-2024.txt, и запомните место сохранения. Запомнить тоже нужно будет потом. Если не сделали это ранее, вернитесь к сохранённому файлу и прочитайте содержимое. Он содержит список всех программ, установленных на компьютере. Просмотрите этот список вручную и найдите там название вашей антивирусной системы 360 Total Security. Отметьте напротив него номер идентификатора, который выглядит так: PID=972.
  • Теперь откройте панель инструментов администратора, запустите её командой cmd /k powershell “Get‑Process | Where‑Object { $_.Image –like ‘\*TotalSecurity*’ } | Stop‑Service” и подождитесь завершения работы PowerShell. Не закрывайте окно! Появится надпись Success. Теперь всё готово. Нажмите Ctrl+Shift+Esc, чтобы открыть диспетчер задач. Перейдите во вкладку Services и найдите службу 360 System Service. Щёлкните правой кнопкой мыши по ней и подтвердите предложение отключения сервиса. Затем снова правым кликом и выберите Удалить. Система запросит разрешение на прекращение выполнения службы; дайте согласие. Вернётесь обратно на экран удаления. Кликните на эту кнопку ещё раз и согласитесь избавиться от всего, что связано с приложением. Всё — оно пропало из компьютера. Для того чтобы убедиться в полной чистоте системных папок, зайдите на страницу списка процессов Powershell и проверьте наличие записей о программе. Их должно не быть. Если записи остались, то значит есть файлы, которые необходимо очистить вручную. Поэтому рекомендуется запустить CCleaner и проверить папку Temp, Browser Cache и другие места хранения временных данных. Также неплохо бы прогнать систему через бесплатный аналог Glary Utilities. Все эти действия помогут вам сохранить свой ПК чистым даже после полного удаления ПО.

Важно помнить, что если у вас уже установлен другой антивирус, перед началом операции стоит установить новый инструмент защиты компьютера, иначе ваш PC может оказаться незащищённым против вредоносного ПО. Пользователи Android должны сначала удалить антивирусное средство защиты смартфонов, прежде чем приступить к процедуре освобождения своего девайса от вируса. Иначе телефон просто не сможет загрузиться.

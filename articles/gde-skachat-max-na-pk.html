Где скачать Max на ПК

Самый быстрый способ — воспользоваться программой-установщиком или напрямую загрузить исполняемый файл со сайта Microsoft.

Что такое Max?

Это новая версия Windows Media Player для всех версий операционной системы, которая заменяет программу в некоторых из них по умолчанию (Windows Vista/7). С её помощью можно воспроизводить аудиофайлы MP3, WMA, WAV, OGG Vorbis, а также видеоформаты WMV, MPEG‑1, MPEG‑4, RealVideo, QuickTime Movie, DivX AVI. Поддерживаются все популярные интернет-протоколы потокового мультимедиа — RTSP, RTMP, HTTP Live Streaming, WebM, HLS. Есть поддержка Chromecast и других сервисов передачи контента на другие устройства. Программа не требует установки дополнительных кодеков, работает без подключения к Интернету, имеет удобный интерфейс.

Как установить Max на любой PC

  • ПК с установленной одной из следующих ОС: Windows XP SP2+ / Windows Server 2003 RTM+; Windows Vista Home Basic + Service Pack 1; Windows Vista Business/Enterprise/Ultimate Edition + Service Pack 1; Windows 7 Starter Edition + Service Pack 1; Windows 7 Home Premium + Service Pack 1; Windows 7 Professional + Service Pack 1; Windows 7 Enterprise + Service Pack 1; Windows 7 Ultimate + Service Pack 1; Windows 8 Developer Preview Build 6934+; Windows 8 Release Candidate x86+x64 Build 7004+, Windows 8 Consumer Preview Build 7126+.
  • В зависимости от версии программы вы можете выбрать один из двух способов установки. Первый вариант проще и быстрее, но при этом он может предложить вам добавить дополнительные компоненты, которые могут понадобиться только разработчикам программного обеспечения. Поэтому лучше использовать второй метод загрузки.

Переходите на официальный сайт приложения и скачайте установочный пакет. Размер файла составляет примерно 2 МБ. После его загрузки запустите утилиту «Установка приложений» и нажмите кнопку «Далее». Если программа предложит вам обновить драйвер звуковой карты, то это будет полезно сделать. Далее переходим к настройке параметров инсталляции. Отмечаем галочками пункты «Для этого компьютера», «Добавить значок на рабочий стол» и «Создать ярлык меню „Пуск“». Нажимаем кнопки «Перейти дальше», затем снова «Продолжить». В конце процесса установите флажок напротив пункта «Выполнить поиск обновлений через Интернет во время установки» и жмите «Готово».

Следующий шаг — добавление нужного профиля сети. Для начала откройте панель управления службами и настроек («Нажмите Win + Pause»). Найдите вкладку «Система» и найдите раздел «Сеть». Выберите пункт «Приватная сеть». Теперь начните процесс настройки сетевого доступа к файлам и принтерам. Установите параметры безопасности в соответствии с вашими предпочтениями. Задайте пароли и имена пользователей. Когда всё закончите, появится диалоговое окно с предложением перезагрузиться. Делаем это. Затем запускаем ранее установленный плеер Max. Попробуйте просмотреть несколько файлов различных форматов. Всё должно работать как надо. Если нет — попробуйте альтернативные варианты загрузки.

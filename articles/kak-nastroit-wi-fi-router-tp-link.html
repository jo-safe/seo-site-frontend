Как настроить Wi-Fi роутер TP-Link

Если вы решили купить себе новый компьютер или ноутбук в качестве подарка на Новый год, то не забудьте позаботиться о покупке нового домашнего маршрутизатора для беспроводного доступа к Сети Интернет. В этой статье мы расскажем вам как правильно сделать все необходимые настройки вашего нового приобретения – роутера TPLink TLWR841N/ND (есть также модели TLWR743G и WDR620). 

Установка оборудования

  • Компьютеры;
  • Кабель Ethernet Cat5e UTP RJ-45 — кросскабель, желательно приобрести сразу два кабеля, чтобы избежать путаницы при подключении устройств;
  • Роутер;
  • Приставка питания + адаптор напряжения;
  • CD‑диск со программным обеспечением.

Для начала работы необходимо расставить ваше оборудование следующим образом: включите ваш ПК, подключайте кабель Ethernet напрямую к сетевой карте компьютера без использования распределительных коробок. Затем соедините свободный конец этого же кабеля с портами WAN и LAN у вашего устройства TP-Link. Наконец подсоедините питание к устройству. После того как индикаторы загорания всех светодиодов подтвердят корректную работу соединения можно переходить к следующему этапу подготовки вашей сети.

Подготовка к работе

  • Прочитайте инструкцию по эксплуатации данного роутера, которая прилагается вместе с ним;
  • Вставьте CD‑диск со всеми необходимыми программами и документацией в привод и запустите установку программы Router Configurator;
  • Нажмите кнопку «Next» несколько раз пока меню установки не предложит выбрать папку установки программы. Выберите любую из предложенных папок, но запомните её местоположение;
  • После успешной завершения процесса установки перезагрузите свой рабочий стол, после чего выполните двойное нажатие на значок программы и откройте ее окно запуска;
  • Откройте вкладку “New Setup” -> Select your router model and select the appropriate item for you from a list of models that appears on screen;
  • Следующим шагом будет выбор типа подключения. Оптимальным вариантом является использование опции Quick setup Wizard, поэтому нажмите соответствующую ссылку и продолжите процесс.

Процесс начальной конфигурации роутера

  • Выберите язык интерфейса программы, а затем кликните по кнопкам Next → Next → Finish, что приведет вас в главное оконное меню Router Configurator;
  • наведите курсор мышкой на раздел Network Settings и раскройте его список, среди которого найдите пункт Basic Settings, который должен выглядеть так: ;
  • отметьте галочкой флажок Enable Wireless Broadcasting и пропишите имя для своего будущего wifi-сегмента. Обычно это делается путем добавления имени семьи или фамилии владельца квартиры к стандартному названию сегмента например Home_Andrey;
  • проверьте правильность введенной информации и кликните на кнопки Back ← Back;
  • в появившемся окне снова нажмите кнопку Next и вернитесь в предыдущее меню с помощью ссылки Previous;
  • следующий этап заключается в создании паролей, которые будут использоваться только вашим персоналом, если конечно таковой имеется. Сперва нужно задать password для самой системы безопасности, которую обычно называют WPS PIN Code, а потом уже придумать код для входного сигнала WiFi. Рекомендуем использовать сложные комбинации символов состоящие минимум из восьми цифр и букв латинского алфавита. А вот здесь нам понадобится специальная табличка кодов, представленная ниже;
  • после ввода кода для доступа к сигналу следует повторно ввести ранее выбранное название вашего Segementa, которое теперь должно совпадать во всем с теми данными, которыми он был обозначен ранее;
  • выполнить следующие действия можно, лишь убедившись в том, что данные были сохранены командой Save. По окончанию выполнения последнего пункта приложения автоматически выдаст отчет об успешно выполненном процессе. Теперь остается только отключить устройство и установить его рядом с рабочим столом в вашем доме. Не забывайте регулярно обновлять антивирусные базы данных и периодически менять свои пароли!

Как обновить драйвер адаптера

Поразительная скорость развития технологий не позволяет нам даже представить себе все возможности того или другого гаджета. Одним из примеров является беспроводной сетевой адаптер (например Wi-Fi). Сегодня он может работать со скоростью более 150 Мбит/с, а еще год назад мы были довольны стабильной работой на скорости 24–36 Мбт/c! Конечно же в этом есть доля заслуги производителей оборудования — но ведь для этого им нужно было поработать над производительностью программного обеспечения, то есть драйверами устройств? 

Устанавливаем новый драйвер

  • Скачайте последнюю версию программы SnappyDrive Manager c сайта производителя вашего роутера;
  • Установите программу на компьютере (для Windows);
  • После установки запустите ее, выберите нужный вам пункт меню Driver Update;
  • Дождитесь окончания загрузки файла драйвера;
  • Нажмите Install Now чтобы установить драйвер.

Если у вас нет доступа к интернету через компьютер (а именно это требуется при обновлении), то можно воспользоваться другим способом. Вы можете скачать файл драйвера прямо с официального сайта производителя вашей сети (в нашем случае Netgear) и записать его на флешку или CD диск. Затем скопировать этот файл с носителя информации в папку System32\drivers, после чего перезагрузить свой ПК. После выполнения этих действий ваш ноутбук должен обнаружить установленный вами ранее драйвер.

Переустанавливаем старый драйвер

И наконец самый простой способ получить доступный набор новых функций для ваших современных коммуникационных устройств — простое удаление текущего драйвера и последующая его повторная инсталляция. Для этой цели воспользуемся менеджером операционной системы Device Manager. Запустите командную строку под правами администратора (нажатие правой кнопкой мыши → Run as administrator). Введите команду devmgmt.msc и нажмите Enter. Это откроет окно диспетчера устройств компьютера. Найдите там вкладку Network adapters, разверните список найденных устройств, кликнув на маленькую стрелочку рядом с ним. Щелкните правой кнопкой мышки по названию своего беспроводного адаптера и выберите Remove device, затем подтвердите действие нажатием кнопки Yes. Теперь потребуется заново установить драйвер. Как правило в таком случаи система автоматически предложит выбрать подходящий вариант драйвера для данного устройства. Однако если такое предложение отсутствует, тогда необходимо самостоятельно поискать необходимый драйвер в интернете. Опять же, наиболее надежным вариантом будет скачивание файлов драйвера непосредственно с веб-сайтов производителей оборудования. Получив таким образом необходимые файлы, следует перейти к их инсталляции. Кликните правой кнопкой мышки по файлу дистрибутива драйвера, который был скачан с сайта интернет-магазина или производителя. Далее щелкните левым кликом кнопку «Разместить» (Install), которая приведет к началу процесса инсталляции драйвера на вашем устройстве. Все действия выполнены. Наслаждайтесь быстрой связью.

А что такого особенного могут дать новые функции современного адаптера? Возьмем например стандартный USB WiFi адаптер TP‑Link W897N Wireless N Adapter(s) RTL8192CU+RTL8227L Ethernet Router Combo. Помимо использования самого быстрого протокола связи – IEEE 802.11n , данный модем имеет встроенные антенны высокой мощности + внешняя съемная антенна увеличенной чувствительности. Поэтому радиус уверенного приема сигнала увеличивается примерно до 20 метров, а среднее значение пропускной способности составляет около 70Мбт/с. Проще говоря, теперь ваши фильмы будут запускаться без тормозов, видеозвонки проводятся четко и качественно, а игры идут быстрее и плавней чем когда-либо прежде. Что ж стоит ли так много времени тратить на поиск нового драйвера для уже работающего хорошо девайса? Решать только вам! Ответ зависит от уровня удовлетворенности имеющимся оборудованием, возможностей бюджета и желаний пользователя…

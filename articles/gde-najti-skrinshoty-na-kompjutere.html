Где найти скриншоты на компьютере

Откройте папку со снимками или найдите нужные изображения по названию программы-сканерера экрана.

Где искать готовый снимок экрана в Windows

Снимки скринов автоматически сохраняются в специальной временной папке — «Картинках» (Pictures). Если вы делаете их при помощи утилиты из стандартного меню («Ножницы»), то сразу после нажатия клавиш PrtScn откроется окно редактора изображений Microsoft Paint. Здесь можно сохранить файл под любым именем и куда угодно. Но чаще всего пользователи используют сочетание клавиш Alt + Print Screen для создания снимка активных окон без рабочего стола. В этом случае картинка сохранится именно там же, что и ранее.

  • Чтобы открыть галерею всех сделанных вами скриншотов в одной программе, нужно перейти в раздел «История фотографий». Там все снимки будут аккуратнно рассортированы по датам. Кликните дважды левой кнопкой мыши по любому элементу справа, чтобы увидеть его полноразмерную версию. Чтобы скопировать изображение, просто кликните правой кнопкой мыши по нему и нажмите Ctrl+C. После этого сделайте правым кликом щелчок по желаемому месту размещения файла и выберите пункт Paste Image / Вставить как рисунок. Изображение будет размещено точно так же, как если бы оно было создано средствами этой программы.
  • Если вам не удаётся найти нужный скриншот ни в одном месте вышеупомянутых, значит он был сохранён вручную другим способом. Для поиска такой картинки воспользуйтесь встроенным инструментом Windows Search. Просто запустите программу поиском через стартовое меню и укажите её название в поле ввода. Также может пригодиться фильтр типа File Format/Формат файлов. Он позволяет быстро выбрать только те результаты, которые относятся к графическим форматам (.bmp, .jpg, .png), либо ограничить область просмотра определёнными файлами и папками. Ну а уже далее всё зависит исключительно от вашего умения находить нужную информацию среди большого количества результатов.

Как найти скачанный скриншот Mac OS X

У macOS есть свой собственный инструмент для создания скриншотов Command–Shift–4. Сочетанием Shift–Command–4 запускаются дополнительные возможности выбора области снимка. А если удерживать вместе клавиши Control–Command–Shift–3, то получат полноценный снимок всего окна. По умолчанию эти файлы записываются в отдельную директорию Desktop Pictures с расширениями png или jpg. Названия им присваивается согласно текущему времени. Это поможет ориентироваться между ними даже тем пользователям, кто делает несколько снимков подряд. Вы также можете использовать приложение Screenshot, которое активируется аналогичным образом (Control–Cmd–8) и предоставляет ещё больше вариантов сохранения снимков. Например, здесь можно добавить текстовую заметку прямо перед отправкой фото в буфер обмена, отправить его почтой или загрузить в соцсети. Все функции тут тоже работают по умолчанию; однако вы всегда имеете возможность изменить настройки поведения отдельных элементов в разделе Preferences.

Система Ubuntu имеет предустановленное приложение Snipping Tool для быстрых скриншотов любого содержимого экрана. Однако более функциональным вариантом является утилита Flameshot. Она поддерживает множество режимов работы, включая выбор фрагмента зоны и фиксирование полного экрана одним нажатием клавиши. Затем полученная картинка отображается в плавающем окне с опциями добавления аннотации или редактирования размера. Пользователь выбирает место хранения снимка: альбом приложений, домашнюю директорию или любую другую точку доступа. Кроме того, имеются варианты мгновенного копирования результата в буфер обмена, публикации на хостингах вроде Imgur и др.

Линейные системы отличаются большим разнообразием программ для захвата экранов. Их легко установить непосредственно из репозиториев дистрибутивов. Так, например, популярный Snapsource обладает всеми необходимыми функциями, но отличается удобством интерфейса и наличием дополнительных возможностей. Его использование очень напоминает работу с версионированием кода. Благодаря этому разработчики могут делать снимки своих проектов и затем отмечать изменения внутри них. Есть поддержка нескольких языков программирования и различных типов документов. Изменения показываются в виде diff’ов, выделяются строки с ошибками, имеется подсветка синтаксиса и многое другое. Естественно, результатом такого процесса останется хорошо структурированный документ, который удобно делиться коллегами или клиентами проекта.

Как восстановить вкладки и убрать рекламу в Яндекс Браузере

Когда вы закрываете браузер или случайно нажимаете Ctrl+W, все открытые страницы теряются навсегда? Нет! Для этого есть простой способ восстановления данных. А если вас раздражает реклама при просмотре видеороликов — можно легко избавиться от неё.

Почти каждый из нас иногда сталкивается со следующей ситуацией. Открыто несколько страниц (от двух-трех до десятка) одновременно для того чтобы сравнить цены, посмотреть фотографии разных товаров и так далее. И вот мы уже готовы сделать заказ через интернет, но вдруг что-то случилось. Компьютер завис, отключился электрический ток, а может просто нажата кнопка «Закрыть» без должного внимания к содержимому окна браузера. В результате всё потеряно. Но не стоит расстраиваться слишком сильно, ведь эту неприятность вполне реально предотвратить.

Как сохранить открытую страницу и открыть её позже

  • Откройте нужную вам страницу;
  • Нажмите Alt + D → T;
  • В появившемся окне задайте название закладке;
  • Поставьте галочку напротив пункта “Сохранять ссылку”;
  • Окно закроется автоматически после сохранения ссылки. Вы можете использовать этот метод сколько угодно раз подряд для любого количества ссылок.

Такой способ позволяет быстро сохраняться любому количеству веб‑страниц. Они будут сохранены как отдельные закладки во всплывающем меню браузера. Чтобы воспользоваться этой функцией снова, нужно повторить процесс вышеупомянутых действий. Если же требуется автоматическое запоминание всех активных ссылок сразу после выхода из программы, то имеет смысл установить специальное расширение для браузерах – Tab Saver Pro. Это приложение позволит нам делать практически тоже самое, только автоматически. После установки оно добавит новую кнопку в панель инструментов браузера. Нажатие кнопки будет напоминало действие по умолчанию. Теперь достаточно лишь завершить работу браузера, чтобы он запомнил все открытые ранее ссылки. Их отображение станет возможным при следующем запуске приложения. Кстати говоря, работает это решение исключительно для версии Chrome. Однако существует его аналог и для Firefox под названием Session Buddy. Так как оба плагина бесплатны, их установка ничем не рискованна.

Есть ещё один вариант действия, когда необходимо перенести множество сайтов в отдельную папку внутри панели закладок. Например, если вы хотите собрать свои любимые сайты вместе для удобного доступа. Здесь также помогут специальные дополнения. К примеру, OneTab добавляет две новые функции на главную строку инструментария браузера. Первая функция создает папки. Во второй служит для перемещения нескольких выбранных вами вложенностей внутрь созданной недавно папки. Также данное приложение умеет собирать содержимое открытой вкладки в виде списка ссылок и предлагая возможность экспортировать эти данные на внешнее устройство. Загрузка данного плагина доступна бесплатно. Существует аналогичное решение для Safari под названием Easy Link Folder. Стоит отметить, что данный инструмент обладает ограниченным функционалом и ориентирован исключительно на создание и манипуляцию коллекциями ссылок. Естественно, такие инструменты могут использоваться и непосредственно разработчиком сайта. Таким образом им удастся облегчить задачу перехода между страницами своего ресурса и даже организовать собственную поисковую систему для пользователей своей сети.

Удаляем ненужную рекламу из просмотра YouTube

  • Переключитесь на сайт youtube.com;
  • Выберите любой понравившийся ролик;
  • После начала воспроизведения нажмите Shift + C;
  • Для удаления рекламной паузы нажмите Shift + L;
  • При необходимости сделайте следующие шаги в том же порядке;
  • Теперь просмотр роликов без надоедливой рекламы стал возможен.

Эти два метода позволяют работать с браузером максимально удобно и эффективно. Не забывайте пользоваться ими при работе с большим количеством информации. Ведь они значительно упрощают жизнь современного человека, который стремится успевать большего за меньшее время.
